⏺ Line 83 is the start of the ax.text(...) call that writes each ring's number.
  The call runs over lines 83–85:

  ax.text(r_k, 0, str(k), rotation=90, ha='center', va='center',
          fontsize=label_size,
          bbox=dict(facecolor='white', edgecolor='none', pad=1))

  It sits inside the for k loop, so it runs once per ring and puts the number k
  on ring k. Argument by argument:

  - r_k, 0: the (x, y) position in data coordinates, which here are core radii.
    The point is r_k to the right of the center at height 0, so it lands on ring
    k at the 3 o'clock position.
  - str(k): the text to draw. k is an integer, and ax.text wants a string, so
    str(3) becomes '3'.
  - rotation=90: turns the text 90° counterclockwise. At 3 o'clock a circle runs
    straight up and down, so vertical text runs along the ring, as your spec
    asked.
  - ha='center', va='center': horizontal and vertical alignment. They make
    (r_k, 0) the center of the text rather than its lower-left corner, so the
    number sits on the ring line instead of beside it.
  - fontsize=label_size: the size set on line 79, max(5, 14 - n). It shrinks as
    n grows but never goes below 5 points.
  - bbox=dict(...): draws a box behind the text. facecolor='white' fills it
    white so the black ring line doesn't run through the number.
    edgecolor='none' hides the box's outline. pad=1 adds a little white space
    around the digits.

❯ could you tell me how to add grid lines and increase the ticks so that there  
  is one for every tenth                                                        

⏺ Two things are needed: a tick locator that puts a tick every 0.1, and ax.grid
  to draw lines at the ticks.

  A warning about "every tenth": your axes run from −3.3 to 3.3, so a tick every
  0.1 is 66 ticks per axis. If every one had a number, the labels would pile on
  top of each other. The usual approach is graph-paper style:
  - major ticks every 1 core radius, with numbers and a darker grid line;
  - minor ticks every 0.1, with no numbers and a faint grid line.

  Step 1: import the locator. Add this at the top of the file, under import 
  matplotlib.pyplot as plt:
  from matplotlib.ticker import MultipleLocator
  MultipleLocator(x) puts a tick at every multiple of x.

  Step 2: set ticks and grid. Add these lines in the "Set axes properties"
  section, after ax.set_aspect('equal'):
      ax.xaxis.set_major_locator(MultipleLocator(1))    # labeled tick every 1
      ax.yaxis.set_major_locator(MultipleLocator(1))
      ax.xaxis.set_minor_locator(MultipleLocator(0.1))  # small tick every 0.1
      ax.yaxis.set_minor_locator(MultipleLocator(0.1))
      ax.grid(which='major', color='0.6', lw=0.8)       # medium gray
      ax.grid(which='minor', color='0.85', lw=0.4)      # faint gray
      ax.set_axisbelow(True)  # grid behind the tube and rings

  A few notes on these lines:
  - Color as a string number: color='0.6' is a gray level, where '0' is black
    and '1' is white. The minor grid is lighter so it doesn't compete with your
    black rings.
  - set_axisbelow(True): draws the grid underneath everything else. The gray
    tube then covers the grid lines inside it, and the grid doesn't cut across
    your ring labels.
  - Too busy? If the 0.1 grid turns out too dense in the saved PNG, delete the
    which='minor' grid line and keep only the minor tick marks.
